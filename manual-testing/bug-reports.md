### Bug Detail Example: BUG_001
- **Description**: After a failed login attempt, the error message persists even when the user starts typing a new set of credentials.
- **Steps to Reproduce**:
    1. Go to Login page.
    2. Enter wrong password and click Login. (Error appears).
    3. Enter correct password.
- **Expected**: Error message should disappear or update.
- **Actual**: "Invalid email or password" stays on screen until submission.
