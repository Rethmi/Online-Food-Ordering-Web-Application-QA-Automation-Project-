# QA Automation Portfolio Project - Online Food Ordering App

This repository contains a full QA Automation project, suitable for portfolio demonstrations and internship applications. It includes a frontend web application, manual testing documentation, and a Selenium-based automation framework.

## Project Structure

- `frontend/`: The web application (HTML, CSS, JavaScript).
- `manual-testing/`: Test scenarios, test cases, and bug reports.
- `automation-testing/`: Selenium WebDriver + Java + TestNG framework.

## Getting Started

### 1. Frontend
To view the web app, simply open `frontend/index.html` in any modern web browser.

### 2. Manual Testing
The documentation is located in the `manual-testing/` folder. Use these templates to practice manual test execution and reporting.

### 3. Automation Testing
- **Prerequisites**: Java 21, Maven.
- **Framework**: Page Object Model (POM).
- **Execution**: Run `mvn test` in the `automation-testing/` directory.

## Features implemented
- User Registration & Login (Local Persistence)
- Light/Dark Mode Toggle
- Food Menu & Item Selection
- Cart Management (Add/Remove)
- Responsive Design for Mobile & Desktop
- Form Validations & Error Messaging
